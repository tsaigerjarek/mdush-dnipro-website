# Юридичні матеріали

## Статус

Юридичні матеріали ще не підготовлені й не є підставою для публікації.

## Потрібно окремо підготувати та погодити

- політику приватності;
- умови використання сайту;
- правила роботи з фото, відео та авторськими правами;
- порядок отримання дозволів на публічне розміщення матеріалів;
- офіційні реквізити та контакт для звернень;
- вимоги до доступності та зберігання публічних документів.
