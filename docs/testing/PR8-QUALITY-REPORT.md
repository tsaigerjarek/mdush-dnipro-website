# Звіт перевірки MVP — PR №8

## Межі

Перевірено статичну версію сайту після PR №7. Розгортання, домен, DNS, HTTPS і GitHub Actions не входять до цього етапу.

## Автоматичні перевірки

- Astro і TypeScript без помилок та попереджень.
- Успішна статична збірка 11 маршрутів.
- Наявність української мови, основного вмісту та посилання пропуску навігації.
- Рівно один `h1`, унікальний `title` і достатній `meta description` на кожній сторінці.
- Open Graph-метадані, viewport і директиви індексації.
- Альтернативні описи та явні розміри всіх зображень.
- Відсутність повторюваних `id`, технічних `TODO` і неробочих внутрішніх посилань.
- Наявність `robots.txt`.
- Відсутність клієнтських JavaScript-файлів.
- Контраст основного тексту, другорядного тексту, кнопок і фокусу за порогами WCAG AA.

## Виправлення

- Уточнено заголовок і опис головної сторінки.
- Додано базові SEO та Open Graph-метадані.
- Передбачено автоматичні canonical URL після визначення адреси сайту в PR №9.
- Покращено видимість клавіатурного фокусу.
- Активний пункт «Новини» тепер визначається і на сторінках окремих матеріалів.
- Контакти в підвалі розмічено семантичним елементом `address`.
- Непогоджені юридичні сторінки виключено з індексації до затвердження текстів.

## Що перевіряється після розгортання

Lighthouse, реальна швидкість мережі, HTTPS, canonical URL, фінальна карта сайту й доступність production-адреси перевіряються в PR №9, оскільки до розгортання немає публічної URL-адреси.
