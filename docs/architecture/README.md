# Архітектура

## Статус

Підготовка структури. Програмний код і сторінки сайту ще не створюються.

## Принципи та розподіл сховищ

- Українська мова та mobile-first підхід є базовими напрямами майбутнього сайту.
- GitHub є джерелом істини для програмного коду, структури сайту, конфігурації без секретів, погоджених текстів, оптимізованих публічних матеріалів, метаданих і журналу змін.
- Google Drive є основним сховищем великих оригіналів фото й відео, робочих матеріалів, внутрішніх та непублічних документів.
- На сайті та в GitHub зберігати лише погоджені оптимізовані публічні копії.
- Публічний контент має походити з перевірених джерел.
- Фото й відео дітей не додавати автоматично або без перевірки; на поточному етапі реальні матеріали не додаються.
- Персональні та медичні дані дітей не зберігати в репозиторії.

## Майбутні контури

- публічна інформаційна частина;
- розділи команд, новин, календаря та документів;
- окремий процес підготовки й погодження контенту;
- безпечні інтеграції з Google Workspace після окремого проєктування;
- контрольоване розгортання після погодження.
