# План контенту

## Статус

План є організаційним шаблоном. Реальні матеріали додаються лише після підтвердження та погодження.

## Майбутні напрямки

- основна інформація про МДЮСШ Дніпро;
- команди та спортивні напрямки;
- календарі й результати після перевірки;
- новини та події;
- документи для відкритого доступу;
- контакти після підтвердження офіційного джерела.

## Мінімальні поля матеріалу

- назва;
- тип матеріалу;
- український текст;
- джерело;
- дата події та дата підготовки;
- відповідальний за перевірку;
- статус: `TODO`, `на перевірці`, `погоджено`, `опубліковано`;
- пов'язані фото, відео або документи;
- позначка про відсутність персональних і медичних даних дітей.

Непідтверджені поля не заповнювати припущеннями. Великі оригінали медіа не зберігати в репозиторії.
