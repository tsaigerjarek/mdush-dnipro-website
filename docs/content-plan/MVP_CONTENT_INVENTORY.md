# Реєстр контенту для MVP

## Правило

Позначка в цьому реєстрі не означає дозвіл на публікацію. Кожен матеріал має пройти перевірку джерела, редакційне погодження, перевірку приватності та, за потреби, прав на використання.

| Скорочена назва | `TODO` | `TODO` | TODO | Офіційно підтверджено |

| Засновник та підпорядкування | `TODO` | `TODO` | TODO | Погоджено формулювання |

## Статуси

- `TODO` — матеріалу або підтвердження немає;
- `на перевірці` — джерело отримано, але не погоджено;
- `погоджено` — дозволено готувати оптимізовану публічну копію;
- `готово до PR` — матеріал перевірено й оформлено для репозиторію;
- `опубліковано` — матеріал є на погодженому production-сайті.
