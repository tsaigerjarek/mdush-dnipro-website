# Hero-візуал головної сторінки

## Джерело концепції

Візуальна концепція базується на затвердженому макеті МДЮСШ: темно-зелена спортивна композиція, три спортивні образи, локальна архітектура Дніпра та велика назва закладу.

## Призначення

Hero має за 3–5 секунд пояснювати:

1. це офіційний сайт МДЮСШ Дніпро;
2. заклад має три спортивні напрями;
3. футбол — основний напрям;
4. черлідинг — другий напрям і підтримка футбольних команд на домашніх змаганнях;
5. настільний теніс — третій напрям;
6. користувач може перейти до умов вступу або спортивних напрямів.

## Важливе обмеження

Текст не вбудовується у графічний файл. У зображенні залишаються тільки:

- спортсмени;
- темно-зелений фон;
- локальна архітектура;
- декоративні світлові та геометричні елементи.

HTML має містити:

- eyebrow;
- h1;
- короткий опис;
- кнопки;
- три короткі факти про спортивні напрями.

Це потрібно для адаптивності, SEO, доступності та можливості швидко змінювати тексти.

## Композиція

### Desktop

- текстова зона: ліва половина;
- спортивна композиція: права половина;
- футболіст — головний образ;
- черлідерка — верхній або задній план;
- спортсмен із настільного тенісу — окремий впізнаваний образ;
- архітектура Дніпра — фоновий шар із низьким контрастом;
- не дублювати логотип, якщо він уже є в header.

### Mobile

- ключові обличчя та спортивний інвентар мають залишатися у центральній безпечній зоні;
- не розміщувати важливі елементи біля правого краю;
- фон може обрізатися, але жоден спортивний напрям не повинен зникати повністю;
- HTML-текст розміщується поверх затемненого градієнта або окремим блоком над зображенням.

## Обов’язкові файли

Зберігати у:

`public/media/hero/`

Файли:

- `hero-mdush-desktop.webp` — 1920 × 1080;
- `hero-mdush-tablet.webp` — 1600 × 1200;
- `hero-mdush-mobile.webp` — 1080 × 1350;
- `hero-mdush-fallback.jpg` — резервний JPEG 1920 × 1080.

## Рекомендована вага

- desktop: до 450 KB;
- tablet: до 320 KB;
- mobile: до 240 KB;
- fallback JPEG: до 550 KB.

## Вимоги до контенту

- без водяних знаків;
- без чужих клубних емблем;
- без випадкових брендів на формі, якщо немає дозволу;
- без деформації облич, рук, м’яча, ракетки або помпонів;
- настільний теніс має читатися саме як настільний теніс;
- права на всі фотографії або графічні елементи мають бути підтверджені;
- не використовувати персональні дані неповнолітніх у назвах файлів або метаданих.

## HTML-структура

Рекомендована реалізація:

```astro
<picture class="hero-visual">
  <source media="(max-width: 767px)" srcset={withBase('/media/hero/hero-mdush-mobile.webp')} />
  <source media="(max-width: 1199px)" srcset={withBase('/media/hero/hero-mdush-tablet.webp')} />
  <source type="image/webp" srcset={withBase('/media/hero/hero-mdush-desktop.webp')} />
  <img
    src={withBase('/media/hero/hero-mdush-fallback.jpg')}
    alt="Вихованці трьох спортивних напрямів МДЮСШ Дніпро: футболу, черлідингу та настільного тенісу"
    width="1920"
    height="1080"
    fetchpriority="high"
    decoding="async"
  />
</picture>
```

## CSS-вимоги

- `object-fit: cover`;
- контроль `object-position` окремо для desktop/tablet/mobile;
- без фіксованої висоти, яка ламає мобільну версію;
- мінімізація layout shift через width/height або aspect-ratio;
- текст має зберігати достатній контраст;
- підтримати `prefers-reduced-motion`;
- не додавати паралакс або важку анімацію.

## Текст Hero

Eyebrow:

`Комунальний позашкільний навчальний заклад`

H1:

`МДЮСШ Дніпро з ігрових видів спорту`

Опис:

`Заклад об’єднує три спортивні напрями: основний — футбол, другий — черлідинг, третій — настільний теніс.`

Кнопки:

- `Умови вступу`;
- `Напрямки спортивного виховання`.

## Процес погодження

1. Дизайнер експортує 4 файли.
2. PowerShell-скрипт перевіряє назви, розміри й вагу.
3. Codex інтегрує `<picture>` у `src/pages/index.astro`.
4. GPT перевіряє відповідність брифу, текстів та доступності.
5. Запускаються `npm test` і локальний перегляд.
6. Зміни проходять через Pull Request, без прямого редагування `main`.
