# Розгортання

## Поточний статус

Розгортання не налаштоване і не запускалося. Сайт на цьому етапі не створюється та не публікується.

## Передумови для майбутнього рішення

- погоджений стек і структура сайту;
- погоджений домен та відповідальна особа;
- перевірені юридичні матеріали;
- процес редакційного погодження;
- перевірені секрети та права доступу;
- план резервного копіювання й відновлення;
- окреме явне рішення про запуск.

До такого рішення не створювати GitHub Actions, deployment secrets, автоматичні workflow або production-конфігурації. Конкретний провайдер і параметри: `TODO`.
