# Контрольний список сайту для заявки Google Workspace for Education

## Призначення

Список допомагає підготувати сайт і доказову базу до заявки. Він не гарантує схвалення Google: остаточне рішення та актуальні вимоги визначає Google.

## Ідентифікація закладу

- [ ] На сайті є повна офіційна назва.
- [ ] Правовий та освітній статус сформульовані за чинними документами.
- [ ] Видно, що заклад здійснює освітню діяльність, а не є лише спортивним клубом або медіапроєктом.
- [ ] Вказані цільові вікові групи без персональних даних дітей.
- [ ] Засновник і підпорядкування зазначені лише після перевірки.

## Публічна присутність

- [ ] Сайт доступний за власним погодженим доменом.
- [ ] Домен відповідає назві або офіційній ідентичності закладу.
- [ ] Усі ключові сторінки відкриваються без авторизації.
- [ ] Є офіційна адреса та робочі канали зв’язку.
- [ ] Контактна електронна пошта використовує домен закладу після налаштування.
- [ ] Сайт містить актуальні новини або підтвердження регулярної діяльності.

## Документи та довіра

- [ ] Опубліковано тільки погоджені документи без чутливих даних.
- [ ] Є політика приватності.
- [ ] Є правила використання сайту.
- [ ] Дати, назви й реквізити документів перевірені.
- [ ] Інформація на сайті узгоджується з матеріалами заявки.
- [ ] Немає суперечностей між сайтом, доменом, документами й офіційними контактами.

## Безпека та діти

- [ ] Немає відкритих списків дітей, дат народження, адрес, телефонів або медичних даних.
- [ ] Фото й відео мають підтверджене право використання та редакційне погодження.
- [ ] Метадані й геолокацію публічних медіа перевірено.
- [ ] Форми збору даних дітей у MVP відсутні.
- [ ] Сайт працює через HTTPS.

## Перед відправленням заявки

- [ ] Відповідальна особа виконала фінальну редакційну перевірку.
- [ ] Юридичні формулювання погоджені.
- [ ] Усі `TODO` прибрані з публічних сторінок.
- [ ] Посилання й документи перевірені на телефоні та комп’ютері.
- [ ] Збережено перелік джерел, якими підтверджено кожен ключовий факт.
- [ ] Окремо перевірено актуальні офіційні вимоги Google на дату подання.
