## Критична перевірка права на участь

Google вимагає, щоб заклад належав до прийнятної категорії K–12 або вищої освіти, був визнаний державою, формально акредитований і здійснював навчання учнів. Для МДЮСШ Дніпро потрібно документально підтвердити, що український заклад позашкільної освіти з ігрових видів спорту відповідає цій категорії.

- [ ] Підтверджено державне визнання закладу.
- [ ] Підтверджено формальний освітній статус або акредитацію в термінах, прийнятних для перевірки Google.
- [ ] Підтверджено, що заклад безпосередньо навчає вихованців.
- [ ] Підготовлено офіційний документ, який підтверджує освітній статус.
- [ ] Подання виконує працівник або уповноважений представник самого закладу.
- [ ] Якщо домен охоплює також діяльність, що не відповідає Education, для освітнього закладу передбачено окремий домен.

Сайт підсилює заявку, але сам по собі не замінює підтвердження права на участь.

## Ідентифікація закладу

- [ ] На сайті є повна офіційна назва.
- [ ] Правовий та освітній статус сформульовані за чинними документами.
- [ ] Видно, що заклад здійснює освітню діяльність, а не є лише спортивним клубом або медіапроєктом.
- [ ] Вказані цільові вікові групи без персональних даних дітей.
- [ ] Засновник і підпорядкування зазначені лише після перевірки.

## Активний сайт і домен

- [ ] Заклад має активний сайт, пов’язаний саме з його освітньою діяльністю.
- [ ] Сайт доступний за власним погодженим доменом.
- [ ] Право власності або контроль над доменом можна підтвердити в Google Admin.
- [ ] Домен відповідає назві або офіційній ідентичності закладу.
- [ ] Усі ключові сторінки відкриваються без авторизації.
- [ ] Є офіційна адреса та робочі канали зв’язку.
- [ ] Контактна електронна пошта використовує домен закладу після налаштування.
- [ ] Сайт містить актуальні новини або інші підтвердження регулярної діяльності.

## Документи та довіра

- [ ] Підготовлено скан офіційного документа, який підтверджує освітній статус.
- [ ] Опубліковано тільки погоджені документи без чутливих даних.
- [ ] Є політика приватності.
- [ ] Є правила використання сайту.
