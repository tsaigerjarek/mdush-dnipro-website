# Google Workspace

## Статус

Інтеграції з Google Workspace ще не налаштовані та не перевірялися.

## Майбутнє призначення

Google Workspace може використовуватися для погодженого зберігання робочих матеріалів, плану контенту та великих оригіналів медіа окремо від GitHub. У репозиторій потрапляють лише погоджені публічні матеріали та організаційні інструкції.

## Правила

- Ідентифікатори папок, таблиць і доступи не зберігати в документах або комітах як реальні значення.
- Локальні значення інтеграцій зберігати тільки у `.env` на основі безпечного `.env.example`.
- Видавати найменші необхідні права та регулярно переглядати доступи.
- Не зберігати в робочих матеріалах персональні або медичні дані дітей.
- Великі фото й відео тримати окремо; до сайту передавати тільки погоджені оптимізовані копії.
