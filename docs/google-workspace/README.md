# Google Workspace

## Статус

Інтеграції з Google Workspace ще не налаштовані та не перевірялися.

## Розподіл джерел істини та сховищ

- GitHub є джерелом істини для програмного коду, структури сайту, конфігурації без секретів, погоджених текстів, оптимізованих публічних матеріалів, метаданих і журналу змін.
- Google Drive є основним сховищем великих оригіналів фото й відео, робочих матеріалів, внутрішніх та непублічних документів.
- На сайті та в GitHub можуть зберігатися лише погоджені оптимізовані публічні копії.
- Великі оригінали та непублічні матеріали не дублювати в GitHub.

## Майбутнє призначення

Google Drive може використовуватися для погодженого зберігання робочих матеріалів, плану контенту та великих оригіналів медіа окремо від GitHub. У репозиторій потрапляють лише погоджені публічні матеріали та організаційні інструкції.

## Правила доступу та змінних

- Ідентифікатори папок, таблиць і доступи не зберігати в документах, комітах, Issues або Pull Request як реальні значення.
- Не робити ідентифікатори Google Workspace публічними змінними клієнтської частини.
- Локальні значення інтеграцій зберігати тільки у виключеному з Git файлі `.env` на основі безпечного `.env.example`.
- Секрети тестового та production-середовища зберігати у захищеному сховищі відповідної платформи.
- Видавати найменші необхідні права та регулярно переглядати доступи.
- Не зберігати в робочих матеріалах персональні або медичні дані дітей.

## Медіа

Фото й відео дітей не додавати автоматично або без перевірки. Для майбутньої публікації потрібні підтверджене право використання, визначена законна підстава або належне погодження, редакційна перевірка та дозвіл відповідальної особи. Публікувати лише відібрані оптимізовані копії після перевірки метаданих, геолокації, приватної інформації та безпечності контексту. Великі оригінали залишати в Google Drive або іншому окремо погодженому сховищі поза GitHub.

На поточному етапі реальні фото й відео не додавати. У майбутньому офіційні командні або матчеві матеріали можуть бути опубліковані після виконання всіх вимог перевірки та погодження.
