# Офіційний сайт МДЮСШ Дніпро

## Поточний статус

**Підготовка структури**

Цей репозиторій готує організаційну основу майбутнього офіційного сайту МДЮСШ Дніпро. На цьому етапі сайт, сторінки, дизайн, програмний код, GitHub Actions і розгортання не створюються.

## Призначення сайту

Майбутній сайт має стати перевіреним публічним джерелом інформації про діяльність МДЮСШ Дніпро: новини, команди, календарі та результати після підтвердження, документи для відкритого доступу і контактну інформацію. Факти, контакти, склад тренерів, результати та документи публікуються лише після перевірки відповідальною особою.

## Розподіл джерел істини та сховищ

- **GitHub є джерелом істини** для програмного коду, структури сайту, конфігурації без секретів, погоджених текстів, оптимізованих публічних матеріалів, метаданих і журналу змін.
- **Google Drive є основним сховищем** великих оригіналів фото й відео, робочих матеріалів, внутрішніх та непублічних документів.
- На сайті та в GitHub можуть зберігатися лише погоджені оптимізовані публічні копії. Великі оригінали та непублічні робочі матеріали не дублюються в GitHub.
- Зміни до матеріалів у GitHub проходять через окремі гілки та Pull Request. Злиття в `main`, публікація і розгортання можливі лише після явного погодження власника проєкту.

## Захист дітей і даних

Не додавайте до репозиторію персональні або медичні дані дітей, приватні контакти, документи з чутливою інформацією чи секрети. Фото й відео дітей можуть розглядатися для майбутньої публікації лише після перевірки права використання, законної підстави або належного погодження, редакційної перевірки та дозволу відповідальної особи. На поточному етапі реальні фото й відео не додаються.

Непідтверджені відомості позначайте як `TODO`, а не заповнюйте припущеннями. Перед публікацією погоджених оптимізованих копій перевіряйте метадані, геолокацію, приватну інформацію та безпечність контексту.

## Майбутня структура

- `AGENTS.md` — головні правила роботи з репозиторієм.
- `CONTRIBUTING.md` — порядок підготовки змін і Pull Request.
- `CONTENT_GUIDE.md` — правила українських текстів, фото, документів і новин.
- `SECURITY.md` — правила роботи із секретами, доступами та персональними даними.
- `docs/architecture/` — опис майбутньої архітектури без реалізації коду.
- `docs/legal/` — перелік юридичних матеріалів, які ще потрібно підготувати й погодити.
- `docs/content-plan/` — план контенту та статуси перевірки.
- `docs/deployment/` — майбутні умови безпечного розгортання.
- `docs/google-workspace/` — правила підготовки інтеграцій із Google Workspace.
- `public/documents-public/` — лише погоджені документи для відкритого доступу.

До окремого погодження ці каталоги містять тільки організаційні інструкції та шаблони, а не програмний код чи реальні дані.
