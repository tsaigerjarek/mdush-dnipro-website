# Офіційний сайт МДЮСШ Дніпро

## Поточний статус

**MVP підготовлено до контрольованого розгортання**

Репозиторій містить легкий статичний сайт Astro з підтвердженим текстовим наповненням, трьома стартовими новинами, адаптивною дизайн-системою, SEO-метаданими та автоматичними перевірками. PR №9 готує GitHub Pages, але Draft Pull Request не публікує сайт.

## Призначення сайту

Сайт має стати перевіреним публічним джерелом інформації про діяльність МДЮСШ Дніпро та підтримати підготовку заявки на Google Workspace for Education. Факти, контакти, склад тренерів, результати й документи публікуються лише після перевірки відповідальною особою.

## Технічна основа

- Astro у режимі статичної генерації;
- TypeScript у строгому режимі;
- звичайний CSS і системні шрифти;
- Markdown-колекція офіційних новин;
- без клієнтського JavaScript, CMS, бази даних і рекламних трекерів;
- GitHub Pages через GitHub Actions після окремого погодження.

## Розподіл джерел істини та сховищ

- **GitHub є джерелом істини** для програмного коду, структури сайту, конфігурації без секретів, погоджених текстів, оптимізованих публічних матеріалів, метаданих і журналу змін.
- **Google Drive є основним сховищем** великих оригіналів фото й відео, робочих матеріалів, внутрішніх та непублічних документів.
- На сайті та в GitHub можуть зберігатися лише погоджені оптимізовані публічні копії.
- Зміни проходять через окремі гілки та Pull Request. Злиття в `main` і розгортання можливі лише після явного погодження власника проєкту.

## Захист дітей і даних

До репозиторію не додаються персональні або медичні дані дітей, приватні контакти, секрети чи документи з чутливою інформацією. Реальні фото й відео дітей можуть публікуватися лише після перевірки права використання, законної підстави або належного погодження та дозволу відповідальної особи.

## Основні команди

- `npm ci` — встановити зафіксовані залежності;
- `npm run dev` — запустити локальну розробку;
- `npm test` — перевірити TypeScript, збірку, маршрути, якість і production-конфігурацію;
- `npm run build` — створити статичний каталог `dist`.

## Документація

- `AGENTS.md` — правила роботи з репозиторієм;
- `CONTRIBUTING.md` — порядок підготовки змін;
- `CONTENT_GUIDE.md` — правила контенту;
- `SECURITY.md` — безпека, секрети й персональні дані;
- `docs/requirements/MVP.md` — вимоги до MVP;
- `docs/decisions/0002-technical-foundation.md` — технічне рішення;
- `docs/deployment/README.md` — порядок контрольованого розгортання;
- `docs/testing/` — звіти автоматичних перевірок.
