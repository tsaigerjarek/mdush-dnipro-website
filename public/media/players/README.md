# Сховище медіаматеріалів вихованців МДЮСШ Дніпро

## Правила публікації та обробки фотографій вихованців

1. **Правова основа та згода:**
   - Публікація фотографій неповнолітніх вихованців дозволена **виключно** за наявності офіційної письмової згоди батьків або законних представників (`photoApprovedForPublicUse: true`).
   - На поточному етапі реальні фотографії дітей не публікуються; у системі використовуються нейтральні плейсхолдери («Фото готується»).

2. **Формат та оптимізація:**
   - Формат файлів: оптимізований `WebP` або `JPG` високої якості.
   - Співвідношення сторін: портрет **4:5** (наприклад, 480×600 px або 800×1000 px).
   - Стиснення та якість: `quality: 80-85`, без артефактів.

3. **Приватність та метадані (EXIF):**
   - Усі файли перед розміщенням повинні бути **повністю очищені від метаданих EXIF** (геолокація GPS, дата зйомки, серійні номери пристроїв).
   - Заборонено використовувати персональні дані (ПІБ дитини, дати народження) у назві файлу.

4. **Найменування файлів:**
   - Використовувати безпечні канонічні ідентифікатори:
     - Приклад: `player-001.webp`, `player-002.webp`.
   - Один канонічний портретний файл на одного вихованця.
