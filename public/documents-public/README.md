# Публічні документи

До цього каталогу можна додавати лише документи, які:

- офіційно погоджені для відкритого доступу;
- не містять персональних або медичних даних дітей;
- не містять паролів, токенів, приватних контактів чи іншої чутливої інформації;
- мають перевірені назву, дату, версію, джерело та право на розміщення;
- доступні у форматі, придатному для читання на мобільних пристроях.

Перед додаванням документа відповідальна особа має перевірити його зміст і метадані. Якщо погодження або будь-яке поле відсутнє, залишити `TODO` і не додавати файл.

Великі оригінали фото й відео тут не зберігати. Цей каталог не є місцем для внутрішніх, медичних, кадрових або персональних документів.
