# Внесення змін

## Основне правило

Усі зміни до репозиторію виконуються через окрему гілку та Pull Request. Прямі зміни в `main` заборонені.

## Порядок роботи

1. Перед початком перевірити `AGENTS.md`, чинний README та структуру репозиторію.
2. Створити гілку з короткою назвою за напрямом роботи, наприклад `docs/content-guide` або `chore/project-foundation`.
3. Внести лише зміни, що належать до завдання.
4. Перевірити українську мову, джерела фактів, структуру файлів і відсутність секретів та персональних даних.
5. Створити Draft Pull Request із описом змін, перевірок і відкритих питань.
6. Дочекатися перегляду та явного погодження.
7. Зливати в `main`, публікувати або розгортати зміни лише після такого погодження.

## Коміти

- Повідомлення комітів писати українською.
- Один коміт має описувати одну логічну групу змін.
- Не включати в коміт паролі, токени, API-ключі, персональні чи медичні дані.
- Не додавати великі оригінали фото та відео.

## Pull Request

Опис PR має містити:

- мету та короткий перелік змін;
- перелік перевірених файлів;
- результати перевірки безпеки;
- TODO та питання, що потребують рішення;
- підтвердження, що сайт, Actions і розгортання не запускалися, якщо це відповідає завданню.

Draft Pull Request не є дозволом на злиття чи публікацію.
